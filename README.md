# КАДР — концепт сайта фотостудии (Алматы)

Демонстрационный сайт фотостудии. Чистый HTML/CSS/JS, без сборки и зависимостей.

**Живое демо:** https://rootvandal.github.io/kadr-studio/

## Запуск локально

```bash
python -m http.server 8803
```

Открыть http://localhost:8803

## Как поменять бренд

Всё про бренд — в `config.js` → `window.BRAND`: название (`name`), подпись, город, телефон, WhatsApp, соцсети, адрес, часы. Поменяйте `name` — обновятся логотип, `<title>`, слово в футере, текст заявки.

## Контент

- `SERVICES` — 4 жанра съёмки (тексты, состав, срок, цена «от», обложка).
- `WORKS` — портфолио (контактный лист с лайтбоксом); формат `[id, подпись, жанр, EXIF]`.
- `HALLS` — залы студии. `QUICK` — быстрые услуги. `PACKAGES` — пакеты. `FAQ` — вопросы.

Фото — Unsplash (хотлинк по id). Для боевой версии заменить на реальные снимки студии. EXIF-подписи в портфолио условные. Форма записи — демо: проверяет поля и собирает сообщение для WhatsApp, на сервер ничего не отправляет.
